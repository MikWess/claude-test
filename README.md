# AP Computer Science Principles - 14-Week Study Plan

**Exam Date:** May 2025 (AP CSP Exam)
**Start Date:** February 1, 2025
**Duration:** 14 weeks

---

## AP CSP Overview

### The 5 Big Ideas
| Big Idea | Abbreviation | Description |
|----------|--------------|-------------|
| Creative Development | CRD | How computing innovations are developed |
| Data | DAT | How data is represented and used |
| Algorithms & Programming | AAP | How algorithms solve problems |
| Computing Systems & Networks | CSN | How computers and networks work |
| Impact of Computing | IOC | Social, economic, and cultural effects |

### The Exam
- **70 Multiple Choice Questions** (70% of score) - 2 hours
- **Create Performance Task** (30% of score) - 12 hours of class time

## AP CSP Computational Thinking Practices

1. **Computational Solution Design** - Design and evaluate solutions
2. **Algorithms and Program Development** - Develop and implement algorithms
3. **Abstraction in Program Development** - Use abstraction to manage complexity
4. **Code Analysis** - Evaluate and test code
5. **Computing Innovations** - Explain how innovations use computing
6. **Responsible Computing** - Contribute ethically to computing culture

---

## Daily Study Recommendation

1. **Read** the week's concept notes (20 min)
2. **Code** the practice exercises (40 min)
3. **Review** AP-style multiple choice questions (15 min)
4. **Reflect** on how concepts connect to Big Ideas (5 min)

## Create Performance Task

**Due:** Before the AP Exam (submitted through AP Digital Portfolio)

Requirements:
- A program with student-developed algorithm
- A student-developed procedure with at least one parameter
- Written responses about your code

Preparation begins in Week 12, with dedicated time in Week 14.

## How to Use This Repository

1. Work through each week folder in order
2. Each file has exercises marked with `# TODO:`
3. Read the concept notes before coding
4. Complete AP-style practice questions at the end of each week

```bash
pip install -r requirements.txt
```
