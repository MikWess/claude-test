# CS50 Practice Repository

A comprehensive collection of exercises covering fundamental CS50 concepts in Python, HTML/CSS/JS, Flask, and SQL.

## Structure

```
├── 01_python_basics/       # Variables, data types, input/output
├── 02_control_flow/        # Conditionals, loops, functions
├── 03_data_structures/     # Lists, dictionaries, tuples, sets
├── 04_file_io/             # Text files, CSV, JSON
├── 05_error_handling/      # Try/except, validation
├── 06_libraries/           # Using external packages
├── 07_html_css/            # Web fundamentals
├── 08_javascript/          # DOM manipulation, events
├── 09_flask/               # Web app backend
├── 10_sql/                 # Database operations
└── projects/               # Mini projects combining concepts
```

## How to Use

1. Work through each folder in order
2. Each file has exercises marked with `# TODO:`
3. Run tests with `python -m pytest` in each folder
4. Solutions are in the `solutions/` subfolder (try first!)

## Requirements

```bash
pip install -r requirements.txt
```
